- 大厅不提供邀请队友按钮。

- 用户已经通过 Web 原型确认方案 B，因此本轮直接转换和实施，不重复等待预览确认。

## 实现约束

- `BobTestUI.json` 仅作为动态 UI 挂载画板，通过官方 HTML 转换器生成，禁止手写 JSON。
- `MapName001` 运行时继承主关卡 UI 文件，不在子地图重复创建 `BobTestUI.json`。
- 保持 `_G.__BOB_TEST_UI_RUNTIME` 中现有可测试字段名称，避免破坏回归测试。
- UI JSON 生成后必须生成 `ui_tree`，并执行编辑器热更、等待、保存。
- Lua 只调用项目中已存在且已验证的 `y3.ui`、`GameAPI` 和匹配测试接口。
