# 简易匹配测试界面执行规格

## 元数据

- 来源：标准深度访谈
- 工程类型：已有工程增量
- 访谈轮数：5
- 最终歧义：12%
- 收敛阈值：20%
- 上下文：`.omx/context/simple-match-test-ui-20260716T070431Z.md`
- 访谈记录：`.omx/interviews/simple-match-test-ui-20260716T075004Z.md`

## 目标

参考 `F:\release\maps\battle_ground001` 中正式大厅 UI 的事件映射和状态刷新方式，在当前项目增加一个无正式业务依赖的简易测试面板，使测试人员无需依赖快捷键或聊天命令即可验证 `BOB` 的主要能力，并能在模式切换后观察关键运行状态。

## 已确认的工程事实

- 参考项目在 `BOB` 准备就绪后加载 `pub.ui` 并调用 `UI.init()`。
- 参考 UI 绑定 `[0]F1_main_hall` 和 `layout_player_block_leader`，依赖大量大厅资源及业务对象，不能直接复制到当前项目。
- 当前项目仅有基础 UI 资源，不存在上述大厅 UI 和队员预制体。
- 当前 `pub.lua` 已提供创建/加入/离开队伍、开始/取消匹配、本地私人副本、RPC 私人副本、状态查询及聊天所需的 `BOB` 能力。

## 范围内

- 新增独立简易测试 UI 资源和 Lua 绑定逻辑。
- 在 `1001` 大厅模式提供完整可操作面板。
- 显示当前模式、玩家名称、玩家 `aid`、`BOB.state`、是否准备就绪、队伍编号、队长、队员数量、匹配状态和启动状态。
- 显示队员列表，至少包含名称、`aid`、分数、玩家状态和队长标识。
- 提供创建队伍、输入队伍编号加入、离队按钮。
- 提供开始匹配、取消匹配按钮，并根据当前状态启用或禁用。
- 提供本地单人副本、RPC 多人副本按钮。
- 提供队伍/世界聊天频道切换、文本输入、发送按钮和消息列表。
- 消息列表显示消息正文及频道类型；收到消息后自动刷新。
- 操作失败时在面板内显示可见的错误或结果提示，不依赖 `MainTips`。
- 在 `1002` 对局模式保留紧凑只读状态面板，至少显示当前模式、玩家身份和 `BOB` 登录状态。
- 保留现有 `F2` 至 `F10` 快捷键及聊天命令作为备用入口。

## 范围外

- 不复刻 `F:\release` 的美术、动画和正式大厅布局。
- 不迁移完整 `[0]F1_main_hall`、正式预制体或无关 UI 资源。
- 不引入 `MainTips`、`PlayerSave`、`SquadUi` 等正式项目业务依赖。
- 不修改匹配协议、Protobuf 描述、网络编解码或服务器契约。
- 不改变 `BOB` 已有对外行为；只有在 UI 读取状态确有需要时才增加最小只读辅助接口。
- 不新增第三方依赖。

## 决策边界

实现者可以自行决定：

- UI JSON 的布局、尺寸、控件层级、命名与配色。
- 测试 UI Lua 文件的拆分方式。
- 事件驱动刷新与低频定时兜底刷新的组合。
- 消息列表的合理显示上限与旧消息淘汰方式。
- `1002` 状态面板的紧凑布局。

不得自行改变：

- 第一版必需功能集合。
- `1001` 完整面板、`1002` 状态面板的模式边界。
- 现有匹配和网络协议行为。
- 无正式业务依赖、无新增第三方依赖的约束。

## 可测试验收标准

1. 进入 `1001` 后可见完整测试面板；未登录阶段显示连接状态，`BOB` 准备就绪后控件状态正确更新。
2. 两个本地客户端可以分别创建队伍、复制/输入队伍编号并加入同一队伍，双方队员列表同步更新。
3. 队员离队后双方界面能反映最新队伍状态。
4. 队长可以开始匹配，界面切换为匹配中并提供取消；非队长不能发起匹配。
5. 取消匹配后状态和按钮恢复；进入启动阶段后会阻止重复匹配和队伍变更操作。
6. 本地单人副本按钮能够请求进入 `1002`；RPC 多人副本在人数不足时给出可见提示，人数满足时提交当前队员列表。
7. 队伍聊天和世界聊天均可发送；接收消息显示正文与频道标识。
8. 进入 `1002` 后完整操作区隐藏或禁用，但状态面板继续显示模式 `1002`、玩家身份和 `BOB` 登录状态。
9. UI 不引用 `MainTips`、`PlayerSave`、`SquadUi` 或参考项目缺失的大厅预制体。
10. 现有快捷键与聊天命令继续可用。
11. Lua 静态检查无新增错误；至少完成单客户端和双客户端手工流程验证，并记录无法在本地验证的平台跳图限制。

## 风险与假设

- Y3 UI JSON 的手工编辑兼容性需要以当前工程已有资源格式为准，并通过实际加载验证。
- 正式匹配后的平台自动跳图可能无法在纯本地环境完整验证，RPC 私人副本和本地私人副本可覆盖部分模式切换验证。
- `BOB` 当前部分接口只通过日志报告失败，测试 UI 可能需要最小的结果回调适配，但不得改变协议语义。
