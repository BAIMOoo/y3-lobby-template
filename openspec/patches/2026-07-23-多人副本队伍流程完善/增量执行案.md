## Phase 划分

| Phase | 内容 | 使用技能 |
|---|---|---|
| Phase 1 | 现状分析、协议、API 与副本配置预检 | y3-game-spec / y3-lua-pipeline |
| Phase 2 | 初始关卡与副本关卡 UI 补充 | y3-ui-pipeline |
| Phase 3 | 队长校验、队伍操作、返回大厅逻辑 | y3-lua-pipeline |
| Phase 4 | Lua 审查与自动化测试 | y3-lua-review / y3-auto-test |

## 实现约束

- 复用现有 RPC 协议与队伍状态，避免新增依赖。
- 权限校验放在权威状态所在一侧，客户端 UI 仅做操作入口与提示。
- 保留当前工作区已有未提交改动，不做无关重构。
