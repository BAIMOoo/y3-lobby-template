# Scheme B UI assets

Panel and button PNG files are deterministic Y3 UI textures generated by
`tools/generate_scheme_b_ui_assets.ps1`. The full-screen backdrop is a
`gpt-image-2` production asset and is intentionally preserved by that script.

- IDs `134217729` through `134217745` are reserved for this set.
- Filenames intentionally follow Y3's `%ID#########` import convention.
- The palette follows the approved warm-black and restrained-gold Scheme B preview.
- Panel and input textures use 8 px cap insets.
- Button textures use 8 px cap insets for all four interaction states.
- `134217745` is a native 1920x1080 AI-generated backdrop and must not use
  nine-slice scaling.

Run from the repository root:

```powershell
powershell -ExecutionPolicy Bypass -File tools/generate_scheme_b_ui_assets.ps1
```
