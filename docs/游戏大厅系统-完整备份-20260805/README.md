# 游戏大厅系统

本目录是当前项目大厅、组队、匹配、聊天和私人副本功能的统一用户入口。它面向已经掌握 Y3 编辑器基本操作，并能够在项目中接入 Lua 或 ECA 的开发者。

本文档不会要求你阅读 `BOB` 网络内核源码。完成接入时，你只需要选择调用路径、迁移方案，替换目标项目参数并按验证清单检查结果。

## 先选择迁移方案

| 你的目标 | 选择 | 能力范围 | 维护成本 |
| --- | --- | --- | --- |
| 需要大厅连接、组队、匹配、世界/队伍聊天或多人私人副本 | 完整 `BOB` 迁移 | 全部大厅能力 | 较高，但边界稳定 |
| 只需要创建私人副本、分享口令、口令加入和返回大厅 | 轻量私人副本迁移 | 引擎私人副本闭环 | 较低，但需要手动提取或重写 |
| 还没有确定未来是否需要组队、匹配或聊天 | 完整 `BOB` 迁移 | 为后续扩展保留核心 | 推荐 |

轻量方案不是完整方案的“删文件版”。组队、匹配、聊天和多人私人副本共享 `BOB` 核心，不能从中挑一个按钮或函数单独复制。

## 包含的游戏功能

- 大厅与副本上下文连接。
- 创建、加入、离开、解散队伍，转移队长和移出成员。
- 单人或组队匹配，取消匹配。
- 世界聊天和队伍聊天。
- 引擎私人副本、多人私人副本、口令加入和中途加入。
- 返回大厅、受控退出和退出前清理。
- Lua 与 ECA 两条调用路径。
- 完整 `BOB` 与轻量私人副本两条迁移路径。
- 可选测试 UI 接线、自动验证和真实平台验证清单。

## 明确不包含

- 外部项目配置器 `tools/y3-config-editor/` 的使用或迁移。
- Y3 编辑器、Lua 或 ECA 基础教学。
- 当前项目的战斗、单位生成、地形或玩法实现。
- 正式 UI 美术资源制作；只说明功能按钮如何接线。
- `BOB` 后端服务部署、运维和协议开发。
- 地图发布、平台审核和运营流程。

## 事实来源与示例值

文档中的函数名、字段和行为按以下优先级维护：当前源码与运行配置、ECA DSL/正式 JSON、契约测试、旧说明。旧说明只用于定位线索；出现冲突时，以更高优先级来源为准。

维护者核对文档时还应检查这些具体事实入口：
`maps/EntryMap/script/pub/init.lua`
`maps/EntryMap/script/pub/core/bob.lua`
`maps/EntryMap/script/pub/pub.lua`
`maps/EntryMap/script/pub/eca_lobby_api.lua`
`tools/eca/lobby_service_tests.json`
`maps/EntryMap/script/pub/匹配系统说明.md`
`maps/EntryMap/script/pub/ECA大厅服务接口说明.md`
根目录的 `setting.json` 当前没有本大厅系统的专属迁移项，不应为了迁移本系统而直接复制或改写。

文档中出现的地图 ID、关卡 ID、玩法 ID、模式 ID、服务器环境和协议版本均会标为“当前项目示例值”。迁移时必须替换为目标项目实际值，不能直接把示例值当作通用配置。

## 完成标准

完成接入后，你应当能够：

- 说清所用功能属于完整 `BOB` 还是轻量私人副本能力。
- 分别从 Lua 或 ECA 发起请求并处理成功、拒绝和异步完成。
- 在目标项目替换全部项目标识和配置关系。
- 通过本地自动检查，并明确哪些结论只能在真实平台、双客户端和跨地图环境验证。
